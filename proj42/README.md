# Simple Interest Calculator Using Python

## 📌 Project Title

**Simple Interest Calculator Using Python**

## 📖 Description

The Simple Interest Calculator is a beginner-friendly Python project that calculates simple interest and the total amount using the principal amount, rate of interest, and time period.

The project is designed to run in Visual Studio Code and can be uploaded to GitHub as a mini-project.

## 🎯 Objectives

* Calculate simple interest.
* Calculate the final amount.
* Accept user input.
* Validate input values.
* Test the calculation using multiple test cases.
* Demonstrate Python programming fundamentals.

## 🧮 Formula

The simple interest formula is:

```text
SI = (P × R × T) / 100
```

The total amount is:

```text
Amount = P + SI
```

Where:

```text
P = Principal Amount
R = Rate of Interest
T = Time in Years
SI = Simple Interest
```

## ⚙️ Working

1. The user enters the principal amount.
2. The user enters the rate of interest.
3. The user enters the time in years.
4. The program applies the simple interest formula.
5. The calculated interest is displayed.
6. The total amount is calculated and displayed.

## ▶️ How to Run in VS Code

### Step 1: Install Python

Install Python 3 on your computer.

### Step 2: Open VS Code

Open the project folder in Visual Studio Code.

### Step 3: Open Terminal

Select:

```text
Terminal → New Terminal
```

